# ШАБЛОН. Это НЕ готовый список — его нужно заполнить блобами с телефона KM4k.
#
# Как заполнить:
#   1. Возьмите точный build fingerprint с телефона:
#        adb shell getprop ro.build.fingerprint
#      и подставьте его в первую строку (шаблон выше).
#   2. Список файлов берите из стоковой прошивки: распакуйте vendor.img / odm.img
#      (payload.bin → payload-dumper) или снимите список с работающего телефона:
#        adb shell ls -R /vendor/etc /vendor/lib64 /vendor/bin > vendor_list.txt
#   3. Формат строки:
#        <путь в блобе>[:<путь в сборке>][;ФЛАГИ]
#      Флаги: FIX_SONAME, DISABLE_DEPS, DISABLE_VENDOR_TEST, KEEP_SYMLINKS, REPLACE_FILES.
#
# Ниже — стартовый шаблон по разделам. Оставьте только те строки, которые действительно
