# Разблокировка загрузчика TECNO SPARK 40C (KM4k)

## Главное

У TECNO пункт **«Заводская разблокировка» (OEM unlocking)** в «Для разработчиков» появляется
**не сразу**: Transsion держит серверный таймер **≥14 дней** с момента регистрации **Tecno ID**.
Счётчик идёт на стороне серверов Transsion, «обнулить» его на телефоне нельзя.

**Практический совет: зарегистрируйте Tecno ID сегодня**, даже если не планируете ставить BlueOS
завтра. Кнопка появится через 14 дней, и дальше всё пойдёт без ожидания.

## Пошагово

1. Зарегистрируйте **Tecno ID** на официальном сайте TECNO (или в приложении Tecno / HiOS).
2. «Настройки» → «О телефоне» → 7 раз нажать «Номер сборки» → включится режим разработчика.
3. «Настройки» → «Система» → «Для разработчиков»:
   * включить **«Отладка по USB»**;
   * включить **«Заводская разблокировка»** — **если пункт уже есть**;
   * если пункта нет — он появится после 14 дней с момента регистрации Tecno ID.
4. Подключите телефон к компьютеру, включите отладку по USB, подтвердите доверие.
5. На компьютере:
   ```
   adb reboot bootloader
   fastboot flashing unlock
   ```
6. На телефоне кнопками громкости выберите **«Unlock the bootloader»** и подтвердите питанием.
7. Телефон перезагрузится. **Данные будут стёрты** — это обязательное поведение.

## Проверка

```
fastboot flashing getvar unlocked     # → unlocked: yes
adb shell getprop ro.boot.flash.locked  # → 0
adb shell getprop ro.boot.verifiedbootstate  # → orange (загрузчик открыт)
```

## Что будет после разблокировки

* При каждой загрузке — предупреждение «загрузчик разблокирован». Это нормально, само не пропадёт.
* Данные стёрты. Заранее сохраните коды двухфакторной защиты (Google Authenticator и т. п.) —
  после сброса их не восстановить.
* **Не выполняйте `fastboot flashing lock`, пока стоит GSI/BlueOS** — телефон не загрузится.
  Подробности: [`../../docs/rollback.md`](../../docs/rollback.md).

## Если пункт OEM Unlocking так и не появился

Официальной альтернативы у TECNO нет:

* часть прошивок вообще не даёт включить OEM Unlocking (тогда нужен сервисный центр TECNO);
* «MTK-донгли» и обходные инструменты — **вне рамок этого комплекта**: они обходят защиту
  загрузчика, их использование может повлечь правовые последствия, а «кирпич» после них
  необратим. Если задача не решается штатно — обращайтесь в авторизованный сервис TECNO.

## Восстановление стоковой прошивки

У TECNO нет `flash.android.com` (это инструмент Google для Pixel). Путь — **SP Flash Tool** с прошивкой
для KM4k. Подробности: [`../../docs/rollback.md`](../../docs/rollback.md), раздел 4.
